MPU6050 接线方案（I2C）

MPU6050 → ESP32 接线表
MPU6050 引脚 → ESP32 引脚 说明
VCC → 3V3 MPU6050 支持 3.3V 供电
GND → GND 共地
SDA → GPIO 21 ESP32 默认 I2C SDA
SCL → GPIO 22 ESP32 默认 I2C SCL
INT → （可选）GPIO 4 中断引脚，初期可不接

注意事项（给初学者）

✓ 可以做
  • MPU6050 用 3.3V 供电（更安全）
  • I2C 引脚可以用任意 GPIO 软件模拟
  • 接好线后再通电
✗ 不要做
  • 不要接 5V 到 MPU6050（虽然有些模块支持，但 3.3V 更安全）
  • 不要带电插拔接线
  • GPIO 34/35 只能做输入，不能输出
