## 版本二：详细版（适合嵌入式岗位）

---

**ESP32 智能手表** | 个人项目 | 2026.05

**项目描述**：基于 ESP32 的多功能智能手表，集成姿态传感、环境监测、运动检测、网络功能

**技术架构**：
- 主控：ESP32-D0WD-V3（双核 240MHz）
- 显示：ILI9341 TFT（240×320，SPI 接口）
- 传感器：MPU6050（I2C，6 轴 IMU）、DHT11（温湿度）
- 框架：ESP-IDF v5.4.4 + FreeRTOS + LVGL 8.4

**核心功能**：
1. **姿态检测**：通过 I2C 读取 MPU6050 数据，计算 Pitch/Roll 角度，实时显示
2. **计步器**：基于加速度峰值检测算法，阈值 0.8g，最小间隔 300ms
3. **运动识别**：通过加速度变化量判断静止/走路/跑步状态
4. **多页面 UI**：5 个功能页面（HOME/SPORT/TOOLS/LIGHT/SYS），按键切换
5. **网络功能**：WiFi STA 模式、NTP 时间同步、天气 API、Web Server

**技术难点与解决方案**：
1. **WiFi + I2C 冲突**：ESP32 WiFi 与硬件 I2C 同时工作时系统崩溃
   - 解决：MPU6050 任务固定到 Core 1，I2C 降频到 100kHz
2. **LVGL 白屏**：直接使用原生 API 导致显示异常
   - 解决：使用 esp_lvgl_port 组件，正确初始化显示驱动
3. **按键重复触发**：机械按键抖动导致多次触发
   - 解决：边沿检测 + 300ms 防抖延迟

**项目成果**：
- 实现完整的智能手表原型，支持 5 个功能页面
- 计步器准确率 >90%（正常步行）
- 系统稳定运行，堆内存使用率 ~42%

**代码仓库**：https://github.com/ningjiange/SMART-WATCH
