# ESP32 智能手表重新设计文档

## 项目概述

将 IMU 手势可视化项目重构为多功能智能手表，保留核心硬件，扩展实用功能。

**目标**：简历项目，展示嵌入式开发能力（传感器驱动、LVGL UI、WiFi 通信、FreeRTOS 多任务）。

**复杂度**：大型项目，分阶段实现。

---

## 硬件清单

| 模块 | 接口 | GPIO 引脚 | 用途 |
|------|------|-----------|------|
| ESP32-WROOM-32 | — | — | 主控 |
| ILI9341 2.4寸 TFT | SPI | SCK=18, MOSI=23, DC=2, CS=15, RST=4 | 显示屏 |
| XPT2046 触摸 | SPI | T_IRQ, T_OUT, T_DIN, T_CS, T_CLK | 触摸屏 |
| MPU6050 | I2C | SDA=32, SCL=33 | 运动传感器 |
| DHT11 | 单总线 | GPIO 25 | 温湿度 |
| 蜂鸣器（有源） | GPIO | GPIO 26 | 报警 |
| 按键1（上翻） | GPIO | GPIO 34 | 上翻/增加 |
| 按键2（下翻） | GPIO | GPIO 35 | 下翻/减少 |
| 按键3（确认） | GPIO | GPIO 13 | 确认/返回 |

**不需要的模块**：W25Q64 Flash、DS3231 时钟

## 界面布局

屏幕 240x320 竖屏，仪表盘风格：

### 主界面
```
┌─────────────────────────┐
│   14:32  周三 5/29      │  ← 顶栏：时间 + 日期
├─────────────────────────┤
│  🌡️  26.5°C    💧 65%   │  ← 温湿度
├─────────────────────────┤
│  Pitch:  3.2°           │
│  [████████░░░░] 52%     │  ← MPU6050 角度
│  Roll:  -0.5°           │
│  [███░░░░░░░░] 47%      │
├─────────────────────────┤
│  ☀️ 晴  28°C  湿度 60%  │  ← 天气信息
├─────────────────────────┤
│  ⏰ 闹钟: 07:30         │  ← 闹钟设置
│  🔔 角度报警: ON        │
└─────────────────────────┘
```

### 页面切换
- 主页：仪表盘
- 运动页：计步器 + 卡路里
- 工具页：秒表 + 倒计时 + 手电筒
- 游戏页：贪吃蛇
- 设置页：闹钟 + 报警阈值

## 交互设计

### 触摸手势

| 手势 | 功能 |
|------|------|
| 左滑 | 下一页 |
| 右滑 | 上一页 |

## FreeRTOS 任务架构

| 任务 | 优先级 | 周期 | 职责 | Core |
|------|--------|------|------|------|
| main_task | 5 | 100ms | 显示更新 | 0 |
| sensor_task | 4 | 1s | DHT11 + MPU6050 | 0 |
| mpu_task | 6 | 50ms | MPU6050 读取 | 1 |
| buzzer_task | 3 | 100ms | 蜂鸣器控制 | 0 |
| wifi_task | 2 | — | NTP + 天气 + Web | 0 |
| pedometer_task | 4 | 100ms | 计步器 | 0 |

**关键点**：
- MPU6050 固定到 Core 1（解决 WiFi 冲突）
- I2C 速度 100kHz
- 天气 API 每 30 分钟更新一次

## 报警条件

| 条件 | 阈值 | 报警方式 |
|------|------|----------|
| 角度超限 | 可设置（默认 30°） | 蜂鸣器短响 |
| 温度超限 | 可设置（默认 35°C） | 蜂鸣器长响 |
| 闹钟 | 用户设置 | 蜂鸣器响 10 秒 |

## 注意事项

1. **RAM 限制**：ESP32 有 520KB RAM，BLE 暂时禁用
2. **I2C 冲突**：MPU6050 和 WiFi 冲突，需固定到 Core 1
3. **天气 API**：使用 wttr.in（免费，无需 API Key）
4. **NTP 服务器**：使用 `pool.ntp.org`
5. **贪吃蛇**：使用 LVGL canvas 绘制
